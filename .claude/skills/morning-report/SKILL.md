# Morning report

Write `raw/YYYY-MM-DD Morning Report.md` with:
1. **Today** — parse `TO DO.md` into a checklist for today.
2. **Revise this** — pick one weak spot from `.claude/memory/memory.md` (or a rotating subject) with a 3-question mini-quiz.
3. **Radar** — 3-5 fresh news items from the web on the owner's main project/interest (from memory/profile), each with a one-line "why it matters" and a link.
4. **One nudge** — a single concrete suggestion (e.g., an IA next step).

Keep it under a screen. Frontmatter: `title`, `tags: [morning-report, daily]`, `created`.
